Le problème des secrets avec les agents IA

Un agent de code comme Claude Code ou Codex lance des commandes dans votre terminal. Si un jeton se trouve dans un fichier .env, une variable d'environnement ou la sortie d'une commande, il finit dans le contexte de l'agent, dans des journaux, et parfois dans une transcription envoyée ailleurs. Coller les secrets à la main ne tient pas, et donner à l'agent tout votre gestionnaire de mots de passe est pire.

verrou run : les secrets entrent, ne sortent jamais

verrou run lance une commande avec les secrets dont elle a besoin dans son environnement. Vos fichiers ne contiennent que des références, ils peuvent donc être commités :

# .env : aucun secret dedans
GITHUB_TOKEN=verrou://GitHub/token
DATABASE_URL=verrou://Production%20DB/url

$ verrou --reason "déploiement" run --env-file .env -- ./deploy.sh
Deploying with token <concealed by Verrou>
  • Sortie masquée. Si la commande affiche un secret, Verrou le remplace par <concealed by Verrou> avant qu'il n'atteigne le terminal ou l'agent.
  • Validés un par un. Chaque secret demande Touch ID, avec le motif donné par l'agent (--reason ou VERROU_REASON). Une validation vaut 5 minutes pour cet élément et ce terminal.
  • Chercher sans voir. verrou search montre titres, identifiants et sites, jamais les mots de passe : un agent trouve seul la bonne référence.

Loin du Mac ? Validez depuis l'iPhone.

Quand l'écran du Mac est verrouillé ou que vous êtes inactif, la demande part vers Verrou sur votre iPhone associé : « Le terminal veut lire GitHub, motif : déploiement ». Face ID, un geste, et la commande continue. Si le coffre du Mac était verrouillé, une seule validation le déverrouille pour cet élément.

  • De bout en bout. Demandes et réponses passent par la base privée de votre propre compte iCloud, scellées entre le Mac et les clés Secure Enclave de l'iPhone. Aucun serveur à nous.
  • La clé du coffre reste sur le Mac. L'iPhone ne fait que valider ; il ne reçoit jamais la clé du coffre du Mac.
  • La notification ne dit rien. Elle indique seulement qu'une demande attend ; le motif s'affiche dans l'app, après Face ID.

Serveur MCP et hooks pour votre agent

verrou mcp est un serveur MCP que Claude Code, Codex et Cursor peuvent utiliser (claude mcp add verrou -- verrou mcp). L'agent trouve des éléments et obtient des références, jamais des valeurs ; pour en utiliser une, il la demande à Verrou, et vous validez.

  • Des noms, jamais des valeurs. L'agent voit les titres, les noms de champs et les références verrou://. Il lance des commandes avec les secrets injectés et reçoit leur sortie masquée.
  • Chaque usage validé. Vous voyez le nom de l'agent et son motif.
  • Un garde-fou. verrou hook install empêche l'agent de lire de lui-même les fichiers .env et les clés privées, et le renvoie vers verrou run.

Agent SSH et signature git

eval "$(verrou ssh-agent)" sert les clés SSH de votre coffre : ssh, git push et git commit -S fonctionnent, et chaque signature demande votre accord.

Et par rapport aux autres

1Password propose un op run comparable dans son outil en ligne de commande, lié à son cloud. Verrou le fait pour un coffre sur votre propre serveur Vaultwarden, avec validation depuis l'iPhone ; voir Verrou ou 1Password.
