Terminal & AI agents

Your agents use your secrets. They never see them.

Verrou hands API keys and passwords to the commands an AI agent runs, keeps them out of its context and your scrollback, and asks you first: Touch ID on the Mac, Face ID on your iPhone when you're away.

The problem with secrets and AI agents

An AI coding agent such as Claude Code or Codex runs commands in your terminal. If a token sits in a .env file, in an environment variable or in a command's output, it ends up in the agent's context, in logs, and sometimes in a transcript sent elsewhere. Pasting secrets by hand doesn't scale, and giving the agent your whole password manager is worse.

verrou run: secrets in, never out

verrou run starts a command with the secrets it needs in its environment. Your files only hold references, so they can be committed:

# .env: no secret in it
GITHUB_TOKEN=verrou://GitHub/token
DATABASE_URL=verrou://Production%20DB/url

$ verrou --reason "deploy" run --env-file .env -- ./deploy.sh
Deploying with token <concealed by Verrou>
  • Masked output. If the command prints a secret, Verrou replaces it with <concealed by Verrou> before it reaches the terminal or the agent.
  • Approved one by one. Each secret asks for Touch ID, with the reason the agent gave (--reason or VERROU_REASON). An approval lasts 5 minutes for that item and that terminal.
  • Search without secrets. verrou search shows titles, usernames and sites, never passwords, so an agent can find the right reference on its own.

Away from your Mac? Approve from your iPhone.

When your Mac's screen is locked or you've been idle, the request goes to Verrou on your paired iPhone: "Terminal wants to read GitHub, reason: deploy". Face ID, one tap, and the command continues. If the Mac's vault was locked, a single approval unlocks it for that one item.

  • End to end. Requests and answers go through your own iCloud private database, sealed between the Mac and the iPhone's Secure Enclave keys. No server of ours.
  • The vault key stays on the Mac. The iPhone only approves; it never receives your Mac's vault key.
  • The notification says nothing. It only tells you a request is waiting; the reason appears in the app, after Face ID.

MCP server and hooks for your agent

verrou mcp is an MCP server that Claude Code, Codex and Cursor can use (claude mcp add verrou -- verrou mcp). The agent finds items and gets references, never values; to use one it asks Verrou, and you approve it.

  • Names, never values. The agent sees titles, field names and verrou:// references. It runs commands with the secrets injected and gets their output masked.
  • Every call approved on its own. Verrou shows the command line and the fields it receives, and separately what the agent says it is for. Approve only commands you understand: the mask hides exact values only, so a command the agent chose can still hand it a value.
  • A guard rail. verrou hook install stops the agent from reading .env files and private keys on its own, and points it to verrou run.

SSH agent and git signing

eval "$(verrou ssh-agent)" serves the SSH keys stored in your vault: ssh, git push and git commit -S work, and each signature asks for your approval.

How it compares

1Password offers a similar op run in its CLI, tied to its cloud. Verrou does it for a vault on your own Vaultwarden server, with approvals from your iPhone; see Verrou vs 1Password.
