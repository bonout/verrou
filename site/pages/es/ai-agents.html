El problema de los secretos y los agentes de IA

Un agente de programación con IA como Claude Code o Codex ejecuta comandos en tu terminal. Si un token está en un archivo .env, en una variable de entorno o en la salida de un comando, acaba en el contexto del agente, en los registros y, a veces, en una transcripción que se envía a otra parte. Pegar secretos a mano no escala, y darle al agente todo tu gestor de contraseñas es peor.

verrou run: los secretos entran, nunca salen

verrou run inicia un comando con los secretos que necesita en su entorno. Tus archivos solo contienen referencias, así que puedes hacer commit de ellos:

# .env: sin ningún secreto dentro
GITHUB_TOKEN=verrou://GitHub/token
DATABASE_URL=verrou://Production%20DB/url

$ verrou --reason "deploy" run --env-file .env -- ./deploy.sh
Deploying with token <concealed by Verrou>
  • Salida enmascarada. Si el comando imprime un secreto, Verrou lo sustituye por <concealed by Verrou> antes de que llegue al terminal o al agente.
  • Aprobados uno a uno. Cada secreto pide Touch ID, con el motivo que ha dado el agente (--reason o VERROU_REASON). Una aprobación dura 5 minutos para ese elemento y ese terminal.
  • Buscar sin secretos. verrou search muestra títulos, nombres de usuario y sitios, nunca contraseñas, para que un agente encuentre por sí solo la referencia correcta.

¿Lejos del Mac? Aprueba desde el iPhone.

Cuando la pantalla de tu Mac está bloqueada o llevas un rato sin usarlo, la solicitud va a Verrou en tu iPhone enlazado: "El terminal quiere leer GitHub, motivo: deploy". Face ID, un toque y el comando continúa. Si la bóveda del Mac estaba bloqueada, una sola aprobación la desbloquea para ese elemento.

  • De extremo a extremo. Las solicitudes y las respuestas pasan por tu propia base de datos privada de iCloud, selladas entre las claves del Secure Enclave del Mac y del iPhone. Sin servidores nuestros.
  • La clave de la bóveda se queda en el Mac. El iPhone solo aprueba; nunca recibe la clave de la bóveda de tu Mac.
  • La notificación no dice nada. Solo te avisa de que hay una solicitud pendiente; el motivo aparece en la app, tras Face ID.

Servidor MCP y hooks para su agente

verrou mcp es un servidor MCP que Claude Code, Codex y Cursor pueden usar (claude mcp add verrou -- verrou mcp). El agente encuentra elementos y obtiene referencias, nunca valores; para usar una, se la pide a Verrou y usted la aprueba.

  • Nombres, nunca valores. El agente ve los títulos, los nombres de los campos y las referencias verrou://. Ejecuta comandos con los secretos inyectados y recibe su salida enmascarada.
  • Cada llamada aprobada por separado. Verrou muestra la línea de comandos y los campos que recibe, y aparte lo que el agente dice querer hacer. Apruebe solo comandos que entienda: la máscara solo oculta valores exactos, así que un comando elegido por el agente aún puede entregarle un valor.
  • Una barrera de protección. verrou hook install impide que el agente lea por su cuenta los archivos .env y las claves privadas, y lo dirige a verrou run.

Agente SSH y firma de git

eval "$(verrou ssh-agent)" sirve las claves SSH guardadas en tu bóveda: ssh, git push y git commit -S funcionan, y cada firma pide tu aprobación.

Cómo se compara

1Password ofrece un op run parecido en su CLI, ligado a su nube. Verrou lo hace para una bóveda en tu propio servidor Vaultwarden, con aprobaciones desde tu iPhone; consulta Verrou frente a 1Password.
