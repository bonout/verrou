## Summary

Verrou's foundations are strong: the clipboard is handled better than most password
managers (concealed, local-only, cleared on lock), the lock state is unmistakable,
offline/pending-sync state is honest everywhere, Reduce Motion is respected, and
every string exists in five languages. The problems cluster in four places:
**(1) the wrong-item and lost-work risks** — on the Mac, the copy shortcuts can act on
an item the search no longer shows, and on both platforms auto-lock and Cancel throw
away an open editor, sometimes with a password already set on a site;
**(2) feedback that only sighted, fast users get** — toasts and errors are never
announced to VoiceOver and vanish after 2.2 s, the Mac login fields have no
accessible names, list rows are not controls, and the extension's pill and banner
are silent; **(3) the extension's edges** — a blank popup when Verrou can't be
reached, popup logins that can't be reached by keyboard, a pill that truncates the
site name (the anti-phishing cue); **(4) wording** — in French, "Identifiant" means
both a login and a username in all three surfaces, and a few labels ("Autre",
"Archiver" as a noun, "Choisir") read wrong.

### The 5 highest-impact fixes

1. **Mac: make copy act on what the user sees (M1).** Typing in search keeps the old
   selection, so ⇧⌘C can copy the password of an item no longer listed, with a toast
   that doesn't name the item. Select the first result on query change, make Return
   copy, and name the item in the toast.
2. **Never lose an open editor (C5, C6).** Auto-lock sets `editor = nil` on both
   platforms (iOS default 60 s, Mac counts only mouse hover as activity); Cancel,
   Esc and swipe-down discard silently. Keep the draft through the lock and ask
   "Discard changes?".
3. **AutoFill (iOS): never replace a passkey silently (I1).** Tapping a login that
   already holds a passkey overwrites it — the site then rejects the user. Mark those
   rows and confirm.
4. **Make feedback reach everyone (C4, M4, M5, E5).** Announce toasts and errors to
   VoiceOver, keep failures on screen ≥ 6 s, give the Mac login/register fields
   accessible names, make list rows real controls, and announce the extension's pill
   and save banner.
5. **Extension popup: never blank, always keyboard-operable (E1, E2).** Show
   "Connecting to Verrou…" at once and fall back to the offline message; render the
   site's logins as buttons.

## Strengths to keep

- **Clipboard discipline**: concealed + transient on the Mac, local-only + expiring on iOS, cleared on lock only if Verrou's copy is still there, and the toast says when.
- **Lock state is unmistakable** and `lock()` wipes every piece of UI state; the iOS app blurs in the app switcher; no secrets in logs.
- **Offline honesty**: pending changes shown at every level (banner, row icon, chip, toast, footer).
- **Extension safety model**: closed shadow DOM, only trusted events act, clickjacking checks, secrets only sent to the matching frame; on real GitHub the right login was suggested at once.
- **Reduce Motion honored** in every custom effect; Increase Contrast has its own accent; all strings exist in fr, en, de, es, it.
